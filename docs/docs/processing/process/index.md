During the process step, you will use a simple UI to churn through the data mostly automatically.

You now have two options for how to use this processing 

* [Just Download](https://github.com/Digital-Naturalism-Laboratories/Mothbot_Process/releases/latest) and then [run the software](https://mothbox.org/docs/processing/process/basic) (recommended)
    * Windows
    * Windows with Cuda speedup
    * Mac OS
    * Linux (experimental)
* or "Hacker Mode" (very advanced only)
    * use the [following detailed steps](https://mothbox.org/docs/processing/process/hacker) for setting up your computer to run scripts.
