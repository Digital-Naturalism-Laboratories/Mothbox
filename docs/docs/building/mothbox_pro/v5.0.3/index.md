# Mothbox Pro v5.0.0 - v5.0.5

These are the build instructions for versions of the Mothbox with **PCB mainboards labeled v5.0.0-v5.0.5**, (the previous version of the Mothbox Pro hardware made between 2025-September 2026). These have been tried and tested in the field, but newer versions have a couple tweaks to make an easier build based on this field testing. 

If you have a v5.0.6 board, head over to the [v5.0.6 instructions](https://digital-naturalism-laboratories.github.io/Mothbox/docs/building/mothbox_pro/v5.0.6) instead.
